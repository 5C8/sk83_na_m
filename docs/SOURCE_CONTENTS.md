# Published source contents

This source snapshot includes handwritten integration and renderer code, shaders,
font data, address/name metadata, and the complete `src/zd_debug` implementation,
including its translated debug routines and embedded initialization snapshot.
The ZD implementation and enhanced font are intentional inclusions.

The main-game and EAWebkit generated implementation under the top-level
`generated/` directory is excluded and must be regenerated locally from the
matching game executables. Original game executables, game data, decompiler
dumps, historical backups, local settings/saves/logs, build outputs, and unused
investigation tools are excluded. The historical ZD research tools referenced
by the detailed ZD notes are not required to compile the checked-in ZD source
and are not bundled here.
